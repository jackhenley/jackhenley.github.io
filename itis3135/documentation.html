Introduction

JavaScript is a lightweight, interpreted programming language with first-class functions.

It is most well-known as the scripting language for Web pages, but it is also used in many non-browser environments such as Node.js.

JavaScript is a prototype-based, multi-paradigm, single-threaded, dynamic language, supporting object-oriented, imperative, and declarative programming styles.

The standards for JavaScript are the ECMAScript Language Specification and the ECMAScript Internationalization API specification.

JavaScript should not be confused with the Java programming language — they are two separate languages with very different syntax, semantics, and use cases.

console.log("Hello, World!");
  • Runs in the browser and on the server
  • Dynamically typed
  • Supports functional and object-oriented programming
Variables and Data Types

JavaScript has three ways to declare variables: var, let, and const.

The let keyword declares a block-scoped local variable, optionally initializing it to a value.

The const keyword declares a block-scoped, read-only named constant.

JavaScript data types include: Number, String, Boolean, null, undefined, Symbol, BigInt, and Object.

Variables declared with var are function-scoped and can be re-declared, which is why let and const are preferred in modern JavaScript.

let name = "Alice"; const age = 30; var legacy = true;
  • Use const by default
  • Use let when reassignment is needed
Functions

Functions are one of the fundamental building blocks in JavaScript. A function is a reusable block of code that performs a task or calculates a value.

You can define a function using a function declaration, function expression, or arrow function syntax.

Arrow functions provide a shorter syntax for writing functions and do not have their own this context.

Functions in JavaScript are first-class objects, meaning they can be assigned to variables, passed as arguments, and returned from other functions.

function greet(name) { return `Hello, ${name}!`; } const add = (a, b) => a + b;
  • Arrow functions are concise and lexically bind this
  • Default parameters allow functions to have fallback values
Control Flow

Control flow is the order in which individual statements, instructions, or function calls are executed or evaluated.

JavaScript supports if, else if, and else statements to execute code based on conditions.

The switch statement evaluates an expression and matches it against several case clauses.

Loops such as for, while, and do...while allow code to be executed repeatedly.

The for...of loop iterates over iterable objects like arrays, and for...in iterates over the enumerable properties of an object.

for (let i = 0; i < 5; i++) { console.log(i); }
  • Use === for strict equality checks
  • The ternary operator is a shorthand for simple if/else expressions
Arrays and Objects

Arrays are ordered collections of values, while objects are unordered collections of key-value pairs.

Arrays have useful built-in methods such as map, filter, reduce, forEach, and find.

Objects can be created using object literal syntax, constructor functions, or the class keyword introduced in ES6.

Destructuring allows you to unpack values from arrays or properties from objects into distinct variables.

The spread operator (...) allows an iterable to be expanded, and rest parameters collect multiple function arguments into an array.

const fruits = ["apple", "banana", "cherry"]; const person = { name: "Bob", age: 25 }; const { name, age } = person;
  • Use Array.isArray() to check if a value is an array
  • Object methods like Object.keys() and Object.values() are handy for iteration
  • The spread operator simplifies copying and merging arrays and objects
